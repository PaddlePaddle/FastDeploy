## 2024-05-24 - [Optimize dataclass serialization with explicit field copying]
**Learning:** `dataclasses.asdict()` recursively deep-copies all fields under the hood. In high-throughput serialization pathways (like metrics reporting per-request via `RequestMetrics.to_dict()`), this recursion introduces significant performance overhead, slowing down the engine's ability to serialize and export metrics.
**Action:** Replace `dataclasses.asdict()` with a custom implementation iterating over `__dataclass_fields__` directly. Use shallow copies for primitive types and lists/dicts, and recursively invoke custom `to_dict()` implementations (or fallback to `asdict()`) for nested dataclasses like `SpeculateMetrics`. Module-level imports within functions (`import dataclasses`) are acceptable for micro-optimizations to avoid unused import errors at the module level if the import is only needed dynamically.
