## 2025-03-03 - [FastDeploy `RequestMetrics` Serialization Bottleneck]
**Learning:** `dataclasses.asdict()` evaluates significantly slower due to its deepcopy-like behavior when used extensively in hot paths. In this architecture, it is executed multiple times per request for metrics serialization in `fastdeploy/engine/request.py`. For dataclasses using `slots=True`, manually iterating over `__slots__` and calling `getattr()` is roughly ~3x faster than calling `dataclasses.asdict()`. However, nested dataclass attributes (like `speculate_metrics`) still need to be explicitly serialized with `asdict()` or handled manually to avoid downstream JSON serialization errors.
**Action:** Always prefer manual serialization over `dataclasses.asdict()` for heavily used dataclasses with `slots=True` in high-throughput engines, but ensure you explicitly handle any nested dataclasses inside the manual serialization logic.
