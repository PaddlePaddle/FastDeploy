
## 2025-03-17 - [Optimizing `dataclass.asdict` performance for high-throughput metrics]
**Learning:** The Python standard library `dataclasses.asdict` function relies heavily on `copy.deepcopy` internally, which recursively deep copies every field. For frequently serialized metrics objects like `RequestMetrics` (where `to_dict` is called multiple times per request/token), this deepcopy overhead becomes a noticeable bottleneck, limiting throughput.
**Action:** When working with high-throughput Dataclasses that need frequent serialization to a dictionary, implement a custom `to_dict` method that iterates through `__dataclass_fields__` directly. By checking for primitive types (`int, float, str, bool, NoneType`), we can skip deep copies for primitives and use `.copy()` for shallow copies of known dictionaries and lists, which increases serialization performance by roughly 1.6x. If nested dataclasses are present, ensure to check for `is_dataclass` and call their respective custom `.to_dict()` methods if available.
